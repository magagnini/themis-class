Instruções para Adicionar as Logos no Sistema:

1. Coloque nesta pasta (public/imagens/) as duas imagens com os seguintes nomes exatos:

   - logo_sistema.png     (Logo principal do sistema - substitui o texto "Themis Class")
   - logo_magagnini.png   (Logo da Magagnini Educação - exibido logo abaixo no menu lateral)

2. Formato Recomendado:
   - Formato: PNG com fundo transparente (ou SVG / JPG)
   - Resolução sugerida para logo_sistema.png: ~300x100px ou maior proporção
   - Resolução sugerida para logo_magagnini.png: ~250x60px ou maior proporção

Assim que os arquivos forem salvos nesta pasta, o sistema passará a exibi-los automaticamente tanto na tela de Login quanto no Menu Lateral!
